# Policy Quoting API

A small Django REST Framework service for quoting insurance policies, built to practice a Django/Postgres/Redis stack ahead of a technical interview.

## Stack

Django 5, Django REST Framework, PostgreSQL, Redis, Docker Compose.

## Status

Early scaffolding. Project and app structure are in place; models, API endpoints, and the Postgres/Redis setup are still to come.

## Running it

```bash
python manage.py runserver
```
